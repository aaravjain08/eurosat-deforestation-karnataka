This repository contains the code and pipeline for a research project evaluating a low-cost, transfer-learning approach to satellite-based deforestation detection. A ResNet50 classifier, pretrained on ImageNet and fine-tuned on the EuroSAT land-cover dataset (95.68% test accuracy), was applied to Sentinel-2 imagery of a forest-agriculture boundary region in Uttara Kannada, Karnataka, India, comparing land-cover predictions between 2018 and 2024 to detect candidate forest-loss events. Classifier outputs were then benchmarked directly against Global Forest Watch's independent Hansen Global Forest Change dataset for the same region and time period.

The pipeline includes classifier training, Sentinel-2 imagery acquisition and preprocessing via Google Earth Engine, an NDWI-based correction for water misclassification in hilly terrain, confidence-filtered tile-level change detection, and a full gap analysis comparing results against Global Forest Watch. The project's central finding is that strong benchmark accuracy does not guarantee reliable real-world change detection: diffuse, sub-tile-scale forest loss was systematically underdetected by whole-tile classification, a limitation explained and quantified in the accompanying paper.

All data sources used are publicly available (EuroSAT, Sentinel-2, Global Forest Watch/Hansen). Full methodology, reproducibility details, and results are documented in the accompanying paper.
